# tenmaypcba.com  robots.txt
# Updated: 2026-11-19
#
# Policy: allow all crawling, block parameterized URLs only.
#
# Two layers:
#   1. User-agent: *  -- the actual permission grant. Every crawler
#      that is not named below is allowed here and nowhere else.
#   2. Named groups   -- for the answer-engine crawlers we want to
#      be explicit about. A named group grants nothing extra; it
#      states the same policy in a way the crawler's operator can
#      point at, which is what Anthropic means when it says a rule
#      naming ClaudeBot takes priority over a general preference
#      signal.
#
# Why each named group repeats both directives: robots groups are
# independent. A named group does not inherit anything from
# User-agent: *, so every named group must restate
# "Disallow: /*?*" or that crawler would regain access to the
# parameterized URLs the wildcard blocks.
#
# Reverting is safe: deleting the named groups changes nothing,
# because the wildcard group already allows the same paths.
# ============================================================

User-agent: *
Allow: /
Disallow: /*?*

# Answer-engine crawlers, named explicitly.

# also warn that Cloudflare Bot Fight Mode cannot be skipped by a
# WAF rule, so this file alone cannot guarantee delivery.
#
# Perplexity-User fetches a page because a real user asked for it
# and generally ignores robots.txt, so listing it is a statement
# of intent rather than a control.
