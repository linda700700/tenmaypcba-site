SMT assembly

Paste print, placement and reflow, run as one continuous line with SPI before placement and AOI straight after reflow.

  1. Files received
    Gerber, BOM, centroid checked for completeness
    01
  2. DFM review
    Aperture ratio, panelisation, test-point access
    02
  3. Kit and stencil
    Reels kitted to the program, laser stencil cut
    03
  4. Print and place
    SPI, then Yamaha YSM20 / YSM10 placement
    04
  5. Reflow
    Profile run on a coupon each shift, archived
    05
  6. AOI and X-ray
    Every board inspected, BGA joints radiographed
    06

What to send for an SMT build

You provide
  • Gerber (RS-274X or ODB++)
  • BOM with MPN, reference and quantity
  • Centroid / pick-and-place file
  • Stackup drawing if impedance matters
We check before quoting
  • Aperture area ratio below 0.66 is flagged before stencil cut
  • Board size and panel layout against the 800 × 480 mm window
  • Component spacing for nozzle clearance and reflow shadowing
  • Any part outside 01005 / 0.3 mm pitch goes to an engineer
You receive

Itemised quote, written DFM note, first-article photographs, per-lot AOI record.

THT & box build

Through-hole, hand and selective soldering for the parts that cannot go through reflow — then enclosure, harness and test.

  1. Fixture and pallet
    Masking and support agreed at DFM
    01
  2. THT insertion
    Manual with optical template, or sequenced
    02
  3. Wave or selective
    Nitrogen nozzle for connectors near SMT parts
    03
  4. Hand and post solder
    Workmanship to IPC-A-610, tips checked daily
    04
  5. Box build
    Enclosure, harness, torque and screw records
    05
  6. Final check
    Continuity, function if a rig exists, serial bound
    06

What to send for a THT build

You provide
  • Assembly drawing with polarity and torque notes
  • Enclosure drawing or sample if box build is included
  • Harness drawing and connector part numbers
  • Test specification, or the fixture if you already have one
We check before quoting
  • Connector clearance to neighbouring SMT parts
  • Whether selective soldering is cheaper than wave for this volume
  • Masking areas before conformal coating
  • Packing method if the unit ships retail
You receive

Assembly drawing marked up, torque records, serial-to-lot mapping, packed and labelled units.

Coating & finishing

Conformal coating, potting, depanelising and programming — the steps between a working board and a shippable unit.

  1. Masking plan
    Connectors, test points and contacts agreed
    01
  2. Coating
    Selective spray or dip, acrylic / silicone / urethane
    02
  3. Cure
    Cure schedule recorded per material
    03
  4. Programming
    Checksum verified against the released file
    04
  5. Depaneling
    Router or V-score, edge quality checked
    05
  6. Packing
    ESD bag, desiccant, carton marks agreed
    06

What to send for coating & finishing

You provide
  • Keep-out drawing: what must stay uncoated
  • Coating material and thickness requirement
  • Firmware file plus checksum or version string
  • Panel drawing if the board is still in a panel
We check before quoting
  • Whether the coating reaches under a tall component
  • Programming order relative to coating, so ICs stay accessible
  • Depaneling stress on thin boards
  • Label position and serial format before packing
You receive

Coated and cured boards, programming log, depanelled units, packing photos on request.
